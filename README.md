## 🛠️ Quick Start & Setup

### 1. Initialize Vite Project
To set up a fresh project in the current directory:

```bash
npm create vite@latest .
```

### 2. Clean Up Starter Files
1. Delete `counter.js`.
2. Clear `src/main.js` and keep only:
   ```js
   import './style.css';
   ```
3. Clear `src/style.css` and add a basic reset:
   ```css
   * {
     margin: 0;
     padding: 0;
     box-sizing: border-box;
   }

   body {
     background-color: black;
   }
   ```

## 📜 Commands Reference

| Command | Description |
| :--- | :--- |
| `npm install` | Installs project dependencies defined in `package.json` |
| `npm run dev` | Starts Vite local development server (`http://localhost:5173`) |
| `npm run build` | Builds the production bundle inside `dist/` |
| `npm run preview` | Runs a local preview server for the `dist/` production build |

> **Tip:** Keep the dev server running while working. Vite reloads the page automatically upon saving changes. Press `Ctrl + C` in the terminal to stop the server.

---

## 📁 Project Structure

* `index.html` — Main HTML entry point (imports `/src/main.js`).
* `src/main.js` — JavaScript entry point.
* `src/style.css` — Global styles.
* `dist/` — Compiled production build (generated by `npm run build`; do not edit directly).

## ➕ Creating a New Project

Run these commands from your target parent folder:

```bash
# Create project folder and template
npm create vite@latest my-new-project -- --template vanilla
cd my-new-project

# Install dependencies & GSAP
npm install
npm install gsap

# Start dev server
npm run dev
```

## ⚡ GSAP Cheat Sheet

### Import
```js
import { gsap } from "gsap";
```

### Core Tween Methods
Select elements with standard CSS selectors (e.g., `".box"`, `"#title"`).

```js
// Animate from current state to target values
gsap.to(".box", { x: 100, duration: 1 });

// Animate from specified values to current state
gsap.from(".box", { opacity: 0, y: 50, duration: 1 });

// Define explicit starting and ending values
gsap.fromTo(".box", { opacity: 0, x: -100 }, { opacity: 1, x: 0, duration: 1 });

// Set properties immediately without animation
gsap.set(".box", { x: 0, opacity: 1 });
```

### ScrollTrigger Plugin
For scroll-based animations, register the plugin before creating tweens:

```js
import { gsap } from "gsap";
import { ScrollTrigger } from "gsap/ScrollTrigger";

gsap.registerPlugin(ScrollTrigger);

gsap.to(".box", {
  x: 200,
  scrollTrigger: {
    trigger: ".box",
    start: "top 80%",
    end: "top 30%",
    scrub: true,
  },
});
```
