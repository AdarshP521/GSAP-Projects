## Important commands

Run these from the `gsap_projects/` folder:

| Command | What it does |
| --- | --- |
| `npm install` | Installs dependencies from `package.json`. |
| `npm run dev` | Starts Vite's local development server. Open the URL printed in the terminal (usually `http://localhost:5173`). |
| `npm run build` | Creates the production-ready site in `dist/`. |
| `npm run preview` | Serves the production build locally; run `npm run build` first. |

Keep the development server running while you work. Vite refreshes the browser when you save files. Press `Ctrl+C` in the terminal to stop it.

## Project files

- `index.html` is the HTML entry point. It loads `/src/main.js`.
- `src/main.js` is the JavaScript entry point.
- `src/style.css` contains the app's styles.
- `dist/` is generated by the production build; edit the source files, not the generated files.

To load the stylesheet from JavaScript, add this to `src/main.js`:

```js
import "./style.css";
```

## Create another Vite project

Run these commands from the parent folder where you want the new project:

```powershell
npm create vite@latest my-new-project -- --template vanilla
cd my-new-project
npm install
npm run dev
```

The `vanilla` template creates a plain JavaScript app. To choose a framework or TypeScript instead, omit `-- --template vanilla` and follow the prompts from `npm create vite@latest`.

To use GSAP in a new project:

```powershell
npm install gsap
```

Then import it in your JavaScript:

```js
import { gsap } from "gsap";
```

## GSAP basics

Select elements with CSS selectors, for example `".box"` or `"#title"`. Use `document.querySelectorAll(".box")` to select multiple elements.

```js
gsap.to(".box", { x: 100, duration: 1 });
```

Core tween methods:

- `gsap.to(target, vars)` animates from current values to the supplied values.
- `gsap.from(target, vars)` animates from the supplied values to the current values.
- `gsap.fromTo(target, fromVars, toVars)` defines both start and end values.
- `gsap.set(target, vars)` applies values immediately, without animating.

For scroll-based animations, register the ScrollTrigger plugin before using it:

```js
import { gsap } from "gsap";
import { ScrollTrigger } from "gsap/ScrollTrigger";

gsap.registerPlugin(ScrollTrigger);
```
